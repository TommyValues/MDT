# Ambulance MDT UK

A browser-based UK ambulance MDT/CAD-style roleplay and training interface.

## Features
- Full login screen
- Emergency Care Assistant role and Unit 123
- Home screen inspired by rugged ambulance MDT layouts
- Clickable Crew, Tasks, Incident, Incident History, Navigator, Map, Messages and Crew Duties modules
- Blackpool interactive map
- Address/postcode search
- Road routing / sat-nav using OSRM
- Incident categories C1-C4
- Incident creation and tasking
- Unit status controls
- Nearby unit list
- Persistent incident notes
- Automatic new-job generation
- One job every minute by default
- Audible alert and UK English speech announcement containing category, job type and location
- Settings for voice and job frequency
- GitHub Pages compatible

## Deployment
Upload the contents of this repository to GitHub and enable GitHub Pages using GitHub Actions. The included workflow deploys `index.html` as a static site.

This is a fictional roleplay/training application and is not an operational NHS system.
